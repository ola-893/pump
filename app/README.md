# Pump frontend

From the repository root, run `npm ci`, `npm --prefix app ci`, and `npm run dev`.
Open [Pump](http://127.0.0.1:5197/) to create a local agent, inspect a strategy
and its decision journal, or connect a NEAR testnet wallet to try the vault flow.

The Vite server also runs the local NEAR helper. Use `npm run build` to check the
production build. See the [project README](../README.md) and
[NEAR runbook](../docs/NEAR-DEMO-RUNBOOK.md) for prerequisites and verification.
