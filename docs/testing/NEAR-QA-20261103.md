## Boundaries

Model execution is not hardware-attested. Wallet and runner signatures establish attribution, while journal replay checks consistency and signed 1Click quotes authenticate quote data. A malicious operator or compromised trusted reporter remains within the disclosed trust model.

Shared directory hosting was not publicly provisioned. Real-wallet publishing, multiple physical operator computers and broader scale tests still require acceptance. Public Circle gain-side and loss-side payouts and different entry prices are recorded below. The local helper stays loopback-only. Private models/agents were not uploaded, original journals were preserved and no model weights were duplicated.

## Remaining acceptance limits

- Shared publication has passed automated multi-process acceptance on this Mac. Public HTTPS hosting and real-wallet publication across two physical operator computers have not been demonstrated. Docker is installed, but its daemon was unavailable, so the process test uses Node isolation.
- Historical inference remains operator-reported. Independent evidence verification detects inconsistent accounting, substituted definitions and altered quote bindings. Hardware-backed model execution attestation and protection against an operator fabricating an entirely self-consistent history require further architecture and acceptance.
- Same-period comparison is implemented and tested. Existing records still need sufficient overlapping observations and closed-position samples to support a meaningful empirical comparison.
